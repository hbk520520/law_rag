2026-10-17，本地 Windows x64 / Python 3.13.9，原有 36 项确定性软件回归此前通过。它们使用脚本化模型响应和临时 SQLite 数据库，覆盖证据引文与权重、条件/依赖、多争点、工具反馈、追问恢复、事实更正、预算、API 和引用编号。

此前实际运行还验证了：BGE 与 reranker 在 CUDA 上调用、本地 Qwen 检查点加载、14,620×768 索引有限且归一化、API 启动、离线检索和整条读取。浏览器追问恢复及引用跳转使用夹具数据。

本次工程整理将生成器源码与权重分离，新增发布检查、D 盘存储脚本、固定版本模型准备及 GitHub CI。最新自动检查状态以仓库 Actions 为准；本地检查的实际输出保存在本机 D 盘私有工程记录中。

CI 使用 Windows CPU 锁，模型下载和云端访问关闭；它不验证 GPU 性能、真实云端接口或法律任务质量。没有进行训练、准确率比较、ECE/Brier 评估、校准参数拟合或 Triton 部署验收。有效期元数据尚不完整。
